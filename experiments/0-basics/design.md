# 0-basics

Canonical library source for `diffusion_curvature`. The `0*` notebooks in this directory are the nbdev source of the library: each has `#| export` cells that generate modules under `diffusion_curvature/`.

Unlike other experiments, this directory has no empirical deliverable — it exists so that the foundational library code lives alongside research experiments under a uniform structure.

## Sections

- `0a*` — atoms (kernels, graphs, heat diffusion, spectral entropy, manifold distances)
- `0b*` — baselines (Hickock, Zhang)
- `0c*` — core (`DiffusionCurvature`, diffusion laziness, comparison-space construction, mean flat entropies)
- `0d*` — data (toy manifolds, random surfaces, colosseum, saddle-sphere ablations)
- `0e*` — errata + self-evaluating datasets
- `0g*` — user-facing guide
